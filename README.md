# Dynamic Audio V6

As the name probably sounds very obvious to you. This mod will enhance the audio system for Ravenfield by adding reverb, muffles, delays, and others! (And dont worry, this time I wont use AI to create the description heh)

## Key Features

### Reverb
This is the main thing from this mod. When you battle in a closed space, you should be hearing echoes from gunshots, but the vanilla Ravenfield experience doesnt let you have that. So this mod aims to add that exact thing so that you ear will be blessed by repeating echoes of the same audio.

### Sound Occlusion
To put it simply- C4 behind wall = muffled. C4 right infront of your character = Loud + death

### Light n Sound delay
Tbh this feature is still experimental. It doesnt work 100%, but you can play with the settings if you're interested. Basically make the sound moves slower than light (as it should be)

### Tinnitus (Disabled by default)
Quick note: This one is also experimental. Id recommend to leave it as disabled or else its gonna mess up with the audio system. Tinnitus will basically give u ringing ears when loud happens.

### Fully Configurable
All parameters are customizable via the `DynamicAudio.cfg` OR inside the game itself by pressing F11 (keybind can be changed in the settings too)!. Adjust reverb, occlusion, sound delay, air absorption, tinnitus settings, and more to match your gamer mode.

**V6 Performance Features**:
You can change how the audio detection system works to increase your fps, unless ure using a nasa workstation.

## Installation

1. Download the latest release DLL from the 'Releases' tab
2. Place the `.dll` file into your `BepInEx/plugins` folder
3. Launch Ravenfield - the config file will be automatically generated at `BepInEx/config/DynamicAudio.cfg`
4. Edit the config file to customize settings to your liking!
